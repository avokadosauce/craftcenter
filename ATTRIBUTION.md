Every non-code asset in this repository, with its author, source and license. CraftCenter's own
code and original assets are under the [PolyForm Noncommercial License 1.0.0](LICENSE.md). When you
add an asset, add a row here in the same change; third-party assets must be permissively licensed
and must keep their license file beside them.

## Why the upstream's material may be here at all

CraftCenter contains **none of the Crafting Apps' code**. It downloads their published release
assets, verifies them, and installs them; it never rebuilds or redistributes them. So the upstream
licences bear on exactly two things, and both are settled below:

1. **The app icons.** Each app's repository ships `assets/app-icon/LICENSE.txt`, which states that
   the icon artwork — including the `hicolor/` renders this project uses — is that app owner's
   original work, "licensed like the rest of &lt;the app&gt;, under either of Apache License 2.0 or the
   MIT license, at your option". Both licences permit redistribution with attribution, which is
   what the rows below are. Being permissive, they also allow inclusion in a project licensed more
   narrowly than they are: the icons stay available to anyone downstream under MIT or Apache-2.0,
   whatever CraftCenter's own licence says.
2. **Their names and marks.** Each repository's `docs/brand/LICENSE-brand.txt` states that the
   ArtCraft name, wordmark and mark are trademarks, are **not** open source, and must not appear in
   the name, logo, icon or domain of anything other than the app they belong to. CraftCenter
   therefore carries none of those files, is not named after ArtCraft, and uses the app names only
   to say which app a row installs — the ordinary descriptive use any package manager makes of the
   names of the things it installs.

## Recorded test data

| Path | What it is | Source |
|---|---|---|
| `crates/releases/fixtures/<app>/SHA256SUMS.txt` | The checksum manifest of that app's latest release at the time it was recorded | Fetched from `https://github.com/storytold/<app>/releases/latest/download/SHA256SUMS.txt` |
| `crates/releases/fixtures/<app>/redirect.txt` | The `location` header that request answered with | The same request |
| `crates/releases/fixtures/<app>/latest.json` | The REST API's view of the same release | `https://api.github.com/repos/storytold/<app>/releases/latest` |

These are factual records of published releases, kept so the test suite can run with no network.
They contain no code.
